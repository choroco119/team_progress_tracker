# Team Progress Tracker

製番（製造番号）単位での工程進捗を高密度かつ一覧性に優れた形で管理するための、**完全ローカル動作型の進捗管理ツール**です。  
ブラウザを表示インターフェースとして使用しますが、外部のWebサーバーやクラウドサービス、インターネット通信を一切必要とせず、社内LANのファイル共有環境（またはローカル環境）の閉じた環境下で安全に動作します。複数端末による同時運用・排他制御・デイリー自動バックアップ・進捗差分比較をサーバーレスで実現します。

---

## 🌟 主な機能

- **サーバー不要の多端末同時運用（共有フォルダ同期）**: 
  - ブラウザ標準の **File System Access API** を使用し、社内共有フォルダ上の `team_data.json` を直接読み書き。
  - **排他制御（ロック機能）**: `lock.json` による一時ロックおよび `lastUpdated` タイムスタンプ比較による競合・上書き防止。
  - **アクション時自動同期**: 登録・保存・削除などの操作時に即座に共有フォルダへ反映。
  - **バックグラウンド自動更新**: 30秒ごとの自動リフレッシュにより他端末の変更を検知。
  - **クイック同期**: IndexedDBにフォルダ接続情報を記憶し、ワンクリックで同期再開。
- **自動デイリーバックアップ ＆ ローテーション**: 
  - 共有フォルダ内に `backups` フォルダを自動作成。
  - 毎日最初の接続時に自動でスナップショット（`daily_YYYYMMDD.json`）を保存（直近30日分を自動保持・ローテーション）。
- **製番・6大工程進捗管理**:
  - 納入仕様書、板金手配、部品手配（主部品/予備品/支給品）、銘板手配、社内工事図、ソフト開発の進捗管理。
  - **インクリメンタル検索による過去案件コピー**: 新規登録時、過去の製番・客先・件名から検索して基本情報と各工程の「要・不要」設定を瞬時にコピー。
  - **スクロール可能なカスタムドロップダウン**: 客先・担当者・規格などの選択肢が多い項目において、枠内スクロールリストを採用。
  - **インテリジェント・ツールチップ**: セルホバーで詳細情報をポップアップ表示。画面端での切れ込み防止ロジックを搭載。
  - **連動ハイライト**: 行内ホバー時に左側製番情報エリアが連動ハイライトし、横長テーブルでの視認性維持・追従をサポート。
- **高度なフィルタリング ＆ ソート**: 
  - 工程別「未手配」「未出図」等の絞り込み、キーワード検索、納期昇順・降順ソート。
  - 工程フィルタ使用時は完了済み案件を自動除外し、着手すべき案件に集中可能。
- **アラートシステム**: 
  - 返却期日・詳細図送付リミットの超過を赤字・太字で強調表示。
  - 前工程の進捗に連動した `！要着手`（オレンジバッジ）による着手可能通知。
- **マスターデータ管理**: 
  - 客先名（読みカナ対応）、規格、板金外注先、担当者リストのカスタマイズ。重複登録を自動防止。
- **進捗差分比較機能 (Diff Engine)**:
  - 過去のデイリーバックアップを選択し、現在のデータとの差分を抽出。
  - 重要9項目を一覧表示し、変更箇所を緑字ハイライト。納期順・製番順の複合ソート。

## 🚀 使い方 ＆ 動作環境

### 動作環境
- **対応ブラウザ**: Google Chrome, Microsoft Edge（Chromium系、File System Access API 対応ブラウザ）
- **動作形態**: 完全ローカル・オフライン動作（外部通信なし、Webサーバー不要）
- **セキュリティ要件**: ブラウザの File System Access API 仕様に基づき、**localhost** またはセキュアコンテキスト環境での実行が必要です。

### 起動手順
1. 本リポジトリのディレクトリでローカル環境を準備します（例: PowerShellにて `python -m http.server 8000` またはローカル実行環境）。
2. ブラウザで `http://localhost:8000` を開きます。
3. 画面右上の **「同期設定」** をクリックし、社内LANの共有フォルダ（またはローカル作業フォルダ）を選択します（次回以降は **「クイック同期」** が利用可能）。
4. 案件の追加や、各工程セルをクリックして進捗を入力・保存します。

## 🛠️ 技術スタック ＆ アーキテクチャ

- **フロントエンド**: HTML5, CSS3, JavaScript (ES6+) ※完全ローカル・オフライン動作
- **外部ライブラリ**: Lucide Icons (CDN/ローカル), Google Fonts (Inter)
- **API / ストレージ**: File System Access API, IndexedDB
- **モジュール構造**:
  - [`js/utils.js`](js/utils.js): グローバル状態宣言、フォーマット関数、DOMユーティリティ
  - [`js/sync-manager.js`](js/sync-manager.js): 同期・排他ロック・バックアップマネージャー
  - [`js/diff-engine.js`](js/diff-engine.js): バックアップ比較・差分描画エンジン
  - [`app.js`](app.js): メインUI制御・モーダル制御・イベントハンドリング
