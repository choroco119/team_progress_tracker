Team Progress Tracker 製造工程進捗管理システム 設計仕様書

● 実行環境: ローカルブラウザ環境 (Google Chrome / Microsoft Edge 等)
● 動作形態: 完全ローカル・オフライン動作（Webサーバー不要 / LAN共有フォルダ同期）

01. 概要と開発目的 (What & Why)

Team Progress Tracker は、電気制御盤・機械制御盤・受配電盤などの製造現場において、製番（製造番号）単位での複数工程（納入仕様書・板金手配・部品手配・銘板手配・社内工事図・ソフト開発）の進捗を高密度かつ一覧性に優れた形で管理するための、完全ローカル動作型の進捗管理ツールです。ブラウザを表示インターフェースとして使用しますが、Webサーバーやインターネット通信を一切必要とせず、完全にローカルの閉じた環境（スタンドアロンまたは社内LANのファイル共有）で安全に動作します。

現場の課題 (Before)

  • Excelでの管理によるファイル共有競合、保存ロック、上書きによる更新漏れ
  • 前工程の進捗状況が把握しづらいことによる手待ち時間
  • 返却期日や詳細図送付リミットの見落としによる納期遅延リスク
  • 定例会や朝会での「前回からの変更点抽出」にかかる確認工数

達成仕様と効果 (After)

  • Webサーバー・外部DB不要。社内LANのファイル共有領域を指定することで複数端末からの同時運用が可能
  • 前工程の完了状態に連動した ！要着手 表示による次工程着手判断の補助
  • 返却期日超過・図面リミット超過の即時赤字ハイライト警告
  • 過去バックアップデータとの差分比較により、変更箇所のみを迅速に抽出
完全ローカル・閉域環境動作アーキテクチャ
外部のWebサーバー、クラウドサービス、外部データベースとの通信は一切行いません。ブラウザ標準のローカルファイルアクセス機能（File System Access API）を利用し、端末ローカルまたは社内LAN上の共有フォルダ内にある team_data.json を直接読み書きします。インターネットから完全に隔離された閉域環境・オフライン環境でも同一の操作性で安全に稼働し、社外への情報流出リスクを構造的に排除しています。

02. システムアーキテクチャとデータ同期仕様

複数の担当者が同時に利用する運用に対応するため、排他制御（ロック制御）および自動バックアップ機能を備えています。

機能・機構 技術仕様・動作挙動 メリット・効果
File System Access API ユーザーが指定した共有フォルダのハンドル（dirHandle）を取得し、直接ファイル操作を実行。 専用サーバー不要。社内LANのファイル共有環境で運用可能
排他制御 (Lock Mechanism) データ保存時に lock.json を作成し、他端末からの同時上書きを一時的に待機。ロックファイルのタイムアウト自動解除機構を実装。 同時更新時の競合やデータの上書き不整合を防止
デイリー自動バックアップ 日々の初回接続時、backups/daily_YYYYMMDD.json を自動生成。直近30世代のバックアップファイルを自動保持・ローテーション。 過去データの復元担保および進捗差分比較の入力ソースとして活用
クイック同期 ヘッダーの「最新データに更新」または「クイック同期」操作により、ファイル上の最新データを再読込して画面を即時更新。 他端末で行われた進捗更新を即座に反映

03. 画面レイアウトとデザインシステム

長時間の現場業務における眼精疲労を軽減し、高密度な進捗情報の視認性を確保するため、鳥の子色・深墨茶を基調とした落ち着いた配色設計を採用しています。

① フルHD (1920×1080) 解像度 最適化レイアウト

一般的なオフィスのフルHDディスプレイにおいて、横スクロールなしで基本情報8列＋工程7列の全15列を一画面で俯瞰・確認できます。テーブルヘッダーは上部に固定（Sticky）され、多数の製番行をスクロールしても列見出しが常時表示されます。

② 工程ヘッダーの配色区分とアクセントバー

一覧表の各工程ヘッダー上端には、視認性を高める 3.5px のアクセントバーと淡い背景色を配置しています。各工程は以下のカラーコードで区分されています：

1. 納入仕様書: 鉄紺 (#3B5766) 2. 板金手配: 弁柄 (#B85C43) 3. 部品手配: 黒茶 (#5C4B40) 4. 銘板手配: 常磐緑 (#4E6F5A) 5. 社内工事図: 古代紫 (#6B5B6E) 6. ソフト開発: 鉄紺 (#3B5766) 7. 完了: 弁柄 (#B85C43)

③ 基本情報エリア境界ディバイダー (3px 鉄紺ボーダー)

第8列の「納期」セルの右端に、太さ 3px の鉄紺縦境界線（Dark時は明鉄紺 #678696）を配置。案件の基本情報エリアと、日々更新される工程進捗エリアを明確に視覚区分しています。

ヘッダーの「製番」「納期」をクリックすると昇順・降順を切り替え。現在どの列が有効かを ピル型バッジ（[↑ 昇順] / [↓ 降順]）、背景チントハイライト、下端3pxアクセントライン で表示し、現在の並び順を即座に判別可能です。

05. 進捗差分比較 (Diff Engine) 仕様

前回ミーティング時や過去バックアップ時点からの工程変更点を抽出し、報告・進捗確認業務の効率化を図る比較機能です。

一覧表示とのレイアウト統一 ＆ 列幅均等化

  • 基本情報は 製番 (100px)・客先 (220px)・件名 (295px)・品名 (305px)・納期 (100px) の独立5列で構成
  • 基本情報データ部は製番別進捗一覧と揃えて 左揃え で統一し、客先・件名・品名は一覧と同バランスで余剰幅を最大配分＋ 1行省略＆ホバー時全文ツールチップ表示 を完備
  • パディングを製番別進捗一覧と完全に共通の 0.45rem 0.4rem（上下約7.2px・左右約6.4px）にスリム化
  • 右側工程データ9列すべてを <colgroup> で 納期と同じ100pxの均等幅 に固定（合計幅 1,820px・FHD全幅最適化）
  • white-space: nowrap により日付等の改行（折り返し・縦割れ）を完全防止

複合安定ソート ＆ CUD最適化変更点強調

  • 第1キー「納期昇順」＋ 第2キー「製番昇順（自然順）」 の複合ソート
  • 同日納期の案件が多数存在する場合でも、製番の若い順に自動整列
  • 前回バックアップから変更のあったセルは 常磐緑チント背景 ＋ 太字（Darkモード時は落ち着いた深草色背景 ＋ 高明度CUDエメラルド文字 #4ADE80） でハイライト表示
  • 新規追加された案件も自動検出して差分行として抽出
対象工程 比較対象項目 (全9列・各100px均等幅)

06. 案件登録・編集 ＆ マスターデータ管理

入力誤りや二重登録を防止し、効率的なデータ登録を支援する入力制御機能を備えています。

① 既存案件からの情報一括コピー

新規製番登録モーダル上部の検索窓から過去の類似案件を検索・選択すると、客先・件名・品名・担当者・規格だけでなく、各工程の「要・不要」設定や板金予算まで一括転記されます。リピート案件や類似案件の登録作業を大幅に省力化します。

② 製番の一意性制約 ＆ リアルタイム警告UI

製番入力欄に文字を入力した時点で既存の全製番とリアルタイム照合を行い、重複を検知した場合は入力枠を強調表示し、「※この製番は既に登録されています」と警告を表示します。保存処理時にも最新データと照合し、同一製番の重複登録を確実に抑止します。

③ マスターデータの一意性制約 ＆ Enterキー対応

「設定」モーダル内の各マスターデータ（客先、担当者、規格、板金外注先）において、重複登録および編集時の重複を防止します。入力中のリアルタイム重複判定に加え、Enterキーによる項目追加（日本語入力IME変換確定時の誤動作防止を含む）に対応しています。

07. 操作マニュアル ＆ 運用ステップ (Step-by-Step)

現場導入時の標準的な運用手順です。

  1. 共有フォルダの接続
    初回起動時、ヘッダーの「同期設定」をクリックし、社内LAN上の共有フォルダ（例: \\fileserver\製造部\進捗管理\ または Z:\製造部\進捗管理\）を選択します。接続状態が「同期中」となれば設定完了です。
  2. 新規製番の登録
    ヘッダー右上の「＋新規製番登録」をクリックします。類似案件やリピート案件の場合は「既存案件からコピー」で過去案件を検索して転記し、納期等を設定して「保存」をクリックします。
  3. 日々の工程進捗更新
    一覧表の各工程セル（納入仕様書、板金、部品…）をクリックすると、専用の詳細モーダルが開きます。
    • 「済」ボタンをクリックすると当日の日付が自動入力され、完了状態（常磐緑）となります。
    • 日付欄をクリックしてキーボードから直接 yyyy/mm/dd を打ち込むか、右端のカレンダーアイコンから選択。
  4. 朝会・週次定例での差分比較実行
    上部タブを「進捗差分比較」に切り替え、比較対象とする過去のバックアップファイルを選択して「比較実行」をクリックします。変更のあった工程セルが常磐緑でハイライト表示されます。

Q. フォルダへのアクセス許可が求められる場合:
ブラウザのセキュリティ保護仕様により、ブラウザを完全に閉じて再起動した後はフォルダへのアクセス再許可が必要です。ヘッダーの「同期設定」または「最新データに更新」をクリックし、確認ダイアログで「アクセスを許可」を選択してください。
